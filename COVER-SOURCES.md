# Atlantic cover research

55 consecutive published issues from September 2021 through September 2026, inclusive. Complete archive for the five-year window; 2021 includes September–December, 2022–2024 have 10 issues each, 2025 has 12, 2026 includes January–September.

Primary index: https://www.theatlantic.com/magazine/backissues/

Each record in manifest.json contains the primary issue URL, official issue description, public CDN image URLs, local image path, and official cover-story titles/authors when present. issueTheme contains an official thematic TOC section label for five issues without a Cover Story section. Two additional issues have no named cover section. coverStories must not be presented as exact cover-display typography: online story headlines can differ from print cover wording.

All 55 image downloads succeeded and have valid JPEG or PNG file signatures. 10 are PNG; filenames use matching extensions. All sourced archive thumbnails are 703 pixels wide. The larger TOC image URL is also recorded. September 2026 cover visually inspected.

Source HTML and source JSON are retained for verification. No PDFs, subscriber text, or access-controlled content were downloaded.

Reuse information: https://support.theatlantic.com/hc/en-us/articles/360049974014-Permissions-to-reprint-or-reproduce-content-from-The-Atlantic describes Atlantic reproduction permission and licensed-photo handling. The archive does not state an open license for these images. This research manifest is provenance, not a rights clearance.
